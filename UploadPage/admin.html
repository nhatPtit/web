Quản Lý Sao Lưu & Phục Hồi Dữ Liệu Tòa Soạn

Tạo bản sao lưu toàn diện (Full Database Backup) chuẩn Microsoft SQL Server (.bak) để bảo toàn dữ liệu và phục hồi khi có sự cố.

ℹ️
Nguyên tắc an toàn dữ liệu: Thao tác Sao lưu là an toàn tuyệt đối và không ảnh hưởng đến độc giả hay nhà báo đang tác nghiệp. Thao tác Khôi phục sẽ hoàn trả dữ liệu về đúng thời điểm sao lưu (cần xác thực mật khẩu Admin).

Danh sách các bản sao lưu đã lưu trữ trên máy chủ (.bak)

0 bản sao lưu

Cơ chế sao lưu an toàn

Bản sao lưu được đóng gói bằng câu lệnh SQL Server nguyên bản, chứa đầy đủ các bảng dữ liệu: bài viết, hình ảnh, tài khoản, quảng cáo và biến động giá xăng.

⚠️

Lưu ý khi khôi phục

Khi chọn khôi phục, hệ thống sẽ chuyển database sang chế độ đơn người dùng (SINGLE_USER) và ghi đè dữ liệu hiện tại về bản sao lưu đã chọn.

📂

Định dạng chuẩn

Tên file tự động gán nhãn: WebBao_backup_YYYYMMDD_HHmmss.bak, lưu trữ trực tiếp trong thư mục bảo mật máy chủ.
